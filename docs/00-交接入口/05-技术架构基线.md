# 技术架构基线

更新时间：2026-08-16 20:10（Asia/Shanghai）

- 包名 `@michengai/dsh-notify`，bundle id `dsh-notify`
- TypeScript 源码在 `src`，构建产物在 `lib`
- 宿主走 `agent/status` 与 `userQuestions.ask`，不修改 DSH 内置文件
- 设置读写走 `/api/dsh-notify/config`，聚焦状态走 `/api/dsh-notify/focus`
- Windows 子进程载荷一律 Base64 JSON；PowerShell 脚本必须 UTF-8 BOM
- 状态文件只写 `%DSH_HOME%\dsh-notify`
- 非 win32 平台跳过 Toast 与托盘
