# 项目概览

更新时间：2026-08-16 20:10（Asia/Shanghai）

## 定位

`@michengai/dsh-notify` 是 DeepSeek Harness 的本机通知插件。用户把注意力放在别的窗口时，仍能知道任务完成或需要决策。

## 当前阶段

初始化完成：宿主监听、设置页、Toast/托盘脚本和自制提示音已落地，待本机接入 DSH 后手测。

## 核心能力

- 完成提醒：根 Agent 回合结束
- 决策提醒：包装 `userQuestions.ask`
- 托盘角标：待回复决策 + 未查看完成
- 打扰控制：免打扰时段、跟随系统勿扰

## 稳定边界

- 只做 DSH profile 插件，不改内置包
- 仅 Windows 弹出 Toast 和托盘
- 不联网、无遥测、不读凭据
