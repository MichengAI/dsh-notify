# 总体架构

更新时间：2026-08-16 20:10（Asia/Shanghai）

## 双面插件

`cordis.patch.yml` 插入一行 `dsh-notify`：

- 宿主 `src/index.ts`：监听 `agent/status`，包装 `userQuestions.ask`，注册设置与 HTTP 路由
- 浏览器 `src/client/index.ts`：往设置页注入「通知」区段

## 通知内核

`src/notify/engine.ts` 负责节流、完成合并、托盘状态和拉起 PowerShell。载荷用 Base64，避免 Windows 命令行截断。

## 配置

优先写入 DSH settings 命名空间 `dsh-notify`。设置页不走 apiproxy，只请求：

- `GET/POST /api/dsh-notify/config`
- `POST /api/dsh-notify/preview`

## 运行状态

托盘计数和调试日志只落在 `%DSH_HOME%\dsh-notify`。
